# Series 3 Foundations

[![Deploy Series 3 Foundations to GitHub Pages](https://github.com/jmstbarks/series-3-foundations/actions/workflows/pages.yml/badge.svg)](https://github.com/jmstbarks/series-3-foundations/actions/workflows/pages.yml)

Open [`index.html`](./index.html) in a browser, or run:

```sh
open index.html
```

The site is fully local: lessons, references, assessments, timers, progress tracking, and the isometric hedge simulation require no server or account. Progress is stored only in the browser's local storage.

Launch the low-poly explorable directly at [`simulation/index.html`](./simulation/index.html). It walks a producer or processor hedge through nine stations, with live contract, basis, futures P/L, margin-call, effective-price, and compliance calculations.

## Study rhythm

1. Take the diagnostic without notes.
2. Complete one numbered lesson per study day.
3. Use the linked reference sheet during practice, then retry without it.
4. Run Futures Market Journey after the hedging lessons; answer each station's retrieval prompt before the cart leaves.
5. Take the module checkpoint after each module.
6. Use the cumulative review before the two timed readiness forms.
7. Ask the agent about anything unclear. A lesson is not a learning record until you can apply it correctly.

## Maintenance

```sh
npm run check
```

This rebuilds all generated HTML and checks structure, coverage markers, citations, links, assessment counts, arithmetic fixtures, accessibility basics, and print/mobile CSS.
